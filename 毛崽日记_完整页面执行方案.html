三、各页面核心要素详述

3.1 社区线

社区页 - 推荐流

L1 P0
[状态栏] [导航栏] 毛崽日记 · 搜索 · 消息(红点) [Tab切换] 推荐(选中·珊瑚色下划线) | 关注 [分类筛选] 全部 · 猫咪 · 狗狗 · 其他宠物 (横滑标签) [Feed流] 瀑布流卡片 × N (可滚动) 卡片结构： 宠物头像(42px) + 名字·品种 + 关注按钮 + 时间 风格标签 (傲娇风/热血风/文艺风) 日记标题 (加粗) 日记正文预览 (3行+省略号) 配图区 (1张大图 或 2-3张缩略图横排) 互动栏: 点赞(爱心+数) · 评论(气泡+数) · 分享 · 收藏 [底部Tab栏] 社区选中
  • 推荐流按内容热度排序（综合点赞数、评论数、发布时间加权）
  • 热门日记带"HOT"角标（珊瑚色小标签）
  • 卡片点击 → 进入日记详情页
  • 宠物头像/名字点击 → 进入用户主页
  • 关注按钮：未关注显示珊瑚色描边，已关注显示灰色实心
  • 下拉刷新，上滑加载更多
关键交互
点赞动画：爱心从小到大弹出+轻微震动；双击日记配图也可触发点赞

社区页 - 关注流

L1 P0
[状态栏] [导航栏] 毛崽日记 · 搜索 · 消息(红点) [Tab切换] 推荐 | 关注(选中·珊瑚色下划线) [Feed流] 仅展示已关注用户的最新日记 卡片结构与推荐流一致，但： - 不显示"关注"按钮（已关注状态） - 按发布时间倒序排列（非热度排序） [空状态] (无关注用户时) 插画 + "还没有关注的人" "去推荐页发现更多可爱的毛崽吧" + 跳转按钮 [底部Tab栏] 社区选中
  • 与推荐流共用卡片组件，仅数据源和排序逻辑不同
  • 空状态展示：可爱的宠物插画 + 引导文案 + 跳转推荐页按钮
  • 首次使用引导：如果用户从未关注过任何人，自动展示空状态

日记详情页（共用页面）

L2 P0 多入口共用
[导航栏] ←返回 · "日记详情" · 更多(···) [作者信息条] 宠物头像(48px) + 名字·品种 + 发布时间 关注按钮 (仅他人日记显示) [风格标签] 如"傲娇风" (圆角小标签·珊瑚色) [日记标题] 加粗大字 [日记正文] 完整第一视角文案 (可展开/收起长文) [配图区] 大图展示 / 多图横滑 (带页码指示器) [互动栏·固定底部] 点赞(爱心) · 评论(气泡) · 收藏(书签) · 分享 · 重新生成(仅自己的日记) [评论区] 评论数标题 热门评论 × 2-3 (置顶) 全部评论列表 (头像+昵称+内容+时间+点赞) 回复按钮 → 展开子评论 [评论输入框·固定底部] 头像 + "说点什么..." + 表情 + 发送
  • 入口：首页最近日记 / 社区Feed / 我的日记 / 收藏列表 / 消息通知
  • 自己的日记：显示"重新生成"按钮（回到生成结果页换风格）
  • 他人的日记：显示"关注"按钮，不显示"重新生成"
  • 更多菜单：举报/不感兴趣（他人）/ 编辑/删除（自己）
  • 点赞后爱心变珊瑚色填充+缩放动画
  • 评论支持文字+表情，不支持图片
  • 长文默认展开3行，点击"展开全文"查看完整
关键交互
分享按钮 → 弹出分享面板（微信/朋友圈/微博/QQ/复制链接/生成长图）；删除 → 弹出删除确认弹窗

搜索页

L2 P1
[导航栏] ←返回 · 搜索框(带光标·可输入) · 取消 [搜索前] 历史搜索 (标签云·可单个删除/全部清空) 热门搜索 (带排名序号·红色高亮前3) 热门话题 (#拆家日记大赛 #猫咪迷惑行为) [搜索结果] Tab切换: 日记 | 用户 | 话题 日记结果: 紧凑卡片列表 (头像+标题+预览+点赞数) 用户结果: 用户卡片 (头像+宠物名+品种+关注按钮) 话题结果: 话题卡片 (#话题名 + 参与数 + 关注) [空状态] (无搜索结果) "没有找到相关内容，换个关键词试试？"
  • 搜索范围：日记标题/正文、宠物名字、用户昵称、话题标签
  • 输入时实时联想（防抖300ms）
  • 历史搜索最多保留10条

用户主页

L3 P1

3.2 创作线

创作输入页

L1 P0
[导航栏] ←返回(存草稿确认) · "为Ta写日记" · 存草稿 [选择宠物] 标签 "选择宠物" 横滑宠物卡片 (已建档案) 选中态：珊瑚色边框 + 右上角对勾 无档案时：引导创建卡片 → 跳转添加新宠物 [行为描述] 标签 "描述Ta今天的行为" 多行文本框 (占位："比如：今天把拖鞋藏到了沙发底下，被抓包后还假装无事发生...") 字数统计 (0/500) 快捷模板标签 (横滑): "今天Ta做了什么趣事" / "Ta今天的心情" / "印象深刻的瞬间" [上传照片] 标签 "添加照片（可选）" 网格上传区: 已传照片(可删除×) + 上传按钮(虚线框+) 最多9张 [AI生成按钮] 全宽珊瑚色大按钮 "AI生成日记 →"
  • 从首页底部"+"按钮或宠物档案详情页"为Ta写日记"进入
  • 默认选中最近活跃的宠物（减少操作步骤）
  • 行为描述至少10字才可生成，否则按钮置灰
  • 照片可选，不传也能生成（AI纯文字创作）
  • 存草稿：保存当前输入内容到草稿箱
  • 返回时如有未保存内容 → 弹出"保存草稿/丢弃"确认
关键交互
点击"AI生成日记"→ 进入AI生成中Loading状态；草稿箱中的草稿点击"继续编辑"→ 回到此页并恢复内容

六、执行建议

  1. 批次顺序：按 1→2→3→4→5 执行。创作线（批次2）是App灵魂，社区线（批次1）是留存基础，两者优先完成。
  2. 渲染方式：每个批次渲染为一张SVG/HTML，3-4个手机框并排展示，便于对比页面间跳转关系。复用首页的配色和组件规范。
  3. 共用页面：日记详情页被5个入口共用，只需设计一次，在不同入口下微调（如自己的日记显示"重新生成"按钮）。
  4. 状态优先：Loading状态和弹窗虽然不是独立页面，但影响用户体验感知，需与对应功能页同步设计。
  5. 真实图片：延续首页方案，宠物头像使用真实照片（咪咪.jpg/年糕.jpg/布丁.jpg），新增宠物用SVG占位。
  6. 交互标注：每张原型图右侧用虚线引线标注功能区域名称，与低保真原型保持一致的标注方式。
